# Full Stack Development Assignments

A collection of six small, independent frontend projects built as part of Full Stack Development practice. The repository progresses from fundamental JavaScript concepts and DOM manipulation to React components, props, state management, and controlled forms.

The projects are intentionally kept simple, responsive, and beginner-friendly so that the implementation can be easily explained in a viva or technical interview.

---

## Projects

## Prerequisites

Before running the projects, make sure you have:

* A modern web browser
* Git
* Node.js
* npm

Node.js and npm are required for the React/Vite projects.

You can verify the installations using:

```bash
node --version
npm --version
git --version
```

---

## Clone the Repository

Clone the repository using:

```bash
git clone https://github.com/swaroopmore/FSD.git
```

Move into the project directory:

```bash
cd FSD
```

---

## Running Projects 1–3

Projects 1–3 use plain HTML, CSS, and JavaScript.

No package installation is required.

Open the required project's HTML file directly in a browser.

For example:

```text
1. JavaScript Calculator using Functions/
```

Open its `index.html` file in your browser.

The same approach can be used for Projects 2 and 3.

---

## Running Projects 4–6

Projects 4–6 use React with Vite.

Navigate to the required project folder.

For example:

```bash
cd "4. React Profile Card using Props"
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The same process applies to Projects 5 and 6.

---

## React / Vite Setup

The React projects are created using Vite.

A new React project can be created using:

```bash
npm create vite@latest project-name -- --template react
```

Then move into the project:

```bash
cd project-name
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Production Build

For React projects, create a production build using:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Development Workflow

The projects follow a simple feature-based development workflow.

1. Create the project structure.
2. Build the basic interface.
3. Implement the required functionality.
4. Add validation or interaction where required.
5. Test the project on desktop and mobile.
6. Make meaningful Git commits.
7. Push changes to the repository.
8. Verify the completed project before starting the next assignment.

Each assignment is maintained independently so that its implementation and concepts remain easy to understand.
